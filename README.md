# DeFlockCollege

**Starting a campus ALPR-accountability chapter should cost one student and twenty
minutes — and it should cost exactly that at the 200th school as it did at the first.**

A student goes to the DeFlock site and clicks **"Start a campus community."** They say
which school. The site is generated for them — its own subdomain (`gt.deflock.com`,
`asu.deflock.com`), the local officials who actually decide where the cameras go already
loaded, and one-click buttons that open a pre-written email to each of them.

No meetings. No chartering. No faculty advisor. No logistics. Just actions a student can
take before they have decided whether they are "involved."

## Status

Pre-implementation. Nothing here describes shipped behavior — these documents describe
intent, so that the first line of code has something to be accountable to.

## Terms

**ALPR** — automated license plate reader. Fixed cameras that photograph every passing
plate, log it with a timestamp and location, and retain it in a searchable database.

## Non-affiliation

Every generated chapter site states plainly that it is **not affiliated with, endorsed by,
or sponsored by** the school it is named for. See
[docs/PRODUCT-SPEC.md](docs/PRODUCT-SPEC.md#non-affiliation).
